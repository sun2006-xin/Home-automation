## 2026-11-07｜立项

**背景**：原设计稿《51智慧家居.docx》已完成但未开工。经讨论，明确把它定位为**学习项目**（项目一），与"分布式智能家居"（项目二，见 `../../SmartHome/`）分离推进。

**理由**
- 51 的价值在于"把基本功打熟"，不在"做出现代化的系统"
- 硬把 51 塞进分布式架构，会让它承担力所不及的角色（broker / 网关），两头都做不好
- 两个项目抢同一份时间，备考期更容易双双烂尾。分开后：51 项目可碎片时间做，项目二需整块时间 + 网购元件

**已确定的 4 条修正**（照原文档直做会翻车）
1. 串口独占：HC-05 与 ESP8266 抢 P3.0/P3.1，只能二选一
2. LCD 改 I2C 版（PCF8574），释放 P2.5/2.6/2.7
3. 按键只用 K3/K4，避开串口
4. 去掉 DS1302，MQ-2 走 DO 数字量

**下次从哪继续**
- 阶段一：先写 `bsp/i2c_soft.c`（软件 I2C 正在学，趁热打铁），再上 LCD1602

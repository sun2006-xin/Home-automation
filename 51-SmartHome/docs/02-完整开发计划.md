## 1. 定位与成功标准

### 1.1 这是个什么项目

一块普中A2（STC89C52RC）、一堆外设、全部有线连接、单机闭环。

**它的产品价值为零，学习价值极高。** 目标是把 51 的资源约束（8KB Flash / 256B RAM / 1 个 UART / 无硬件 ADC）每一种都亲手撞一遍，撞完之后对"嵌入式为什么难"有肌肉记忆。

### 1.2 三条成功标准（缺一不可）

| # | 标准 | 判定 |
|---|---|---|
| 1 | **每个模块能从零手写** | 关掉所有参考代码，能默写出时序框架 |
| 2 | **能讲清为什么这样写** | 比如"为什么 DS18B20 要关中断读"、"为什么主循环不能 Delay" |
| 3 | **四阶段各自能独立演示** | 每个阶段有 30 秒能拍成视频的成果 |

### 1.3 明确不管的事

- 不管代码优雅，不管能不能复用到产品（那是项目二的事）
- 不管功耗、不管外壳、不管走线美观
- 不管"能不能真的装在家里"

## 4. 软件分层与模块清单

### 4.1 分层

```
app/        业务：调度器、场景、面板逻辑      ← 唯一允许出现业务判断
protocol/   行协议编解码                       ← 只翻译，不判断
driver/     外设驱动                           ← 只 read/write
bsp/        引脚/时钟/延时/串口/I2C            ← 换板只改这层
```

**审查铁律**：`driver/` 与 `bsp/` 里出现 `if (temp > 30)` 即判缺陷。

### 4.2 模块清单

#### bsp 层

| 模块 | 文件 | 接口（对外） | 关键点 | 工时 | 风险 |
|---|---|---|---|---|---|
| 延时 | `bsp_delay.c` | `void Delay_us(uint16 us)`<br>`void Delay_ms(uint16 ms)` | 11.0592MHz 下需实测校准；`Delay_us` 用于位操作时序 | 1h | 低（但必须示波器验证） |
| GPIO | `bsp_gpio.h` | 宏定义为主，`sbit` 或位操作 | 统一引脚命名，禁止业务层直接写 `P1_0` | 0.5h | 低 |
| 定时器 | `bsp_timer.c` | `void Timer0_Init(void)`<br>`uint16 Timer0_Tick(void)` | 1ms 中断，只做计数器递增，**中断里不做任何业务** | 1h | 中（中断优先级） |

## 5. 主循环调度模型（本项目的技术核心）

### 5.1 为什么不能用 Delay

```c
/* ❌ 这样写的后果：蜂鸣器响 3 秒期间，按键失灵、串口丢包、步进停转 */
Buzzer_On(); Delay_ms(3000); Buzzer_Off();
```

51 没有 RTOS，但**时间片轮询**能解决 90% 的问题。

### 5.2 调度器接口

```c
/* app_sched.h */
typedef struct {
    uint16 period_ms;      /* 周期 */
    uint16 last_ms;        /* 上次执行时刻 */
    void (*task)(void);    /* 任务函数，必须非阻塞、必须短 */
} task_t;

void Sched_Init(void);
void Sched_Run(void);      /* 放在 main 的 while(1) 里，永不返回 */
```

### 5.3 时间片分配表（定稿）

| 任务 | 周期 | 最坏耗时预算 | 说明 |
|---|---|---|---|
| 按键扫描 | 10ms | < 0.2ms | 状态机消抖 |
| 串口轮询 | 10ms | < 0.5ms | 从环形缓冲取行 |
| 步进电机 | 1ms | < 0.1ms | 由定时器中断直接驱动更好 |
| LCD 刷新 | 200ms | < 3ms | 只刷变化的部分 |
| 传感器采集 | 1000ms | < 8ms | DS18B20 读一次约 5ms（含 750ms 转换，需异步） |
| 场景判断 | 200ms | < 0.3ms | 纯逻辑 |
| 状态上报 | 2000ms | < 1ms | 拼行协议发出去 |

> **DS18B20 的坑**：一次转换要 750ms。正确做法是"发转换命令 → 记下时刻 → 1 秒后来取结果"，绝不能 `Delay_ms(750)` 干等。这正是练习非阻塞思维的最佳素材。

### 5.4 main 结构

```c
void main(void) {
    Sched_Init();
    while (1) {
        Sched_Run();
    }
}
```

## 6. 通信协议（行协议）

### 6.1 帧格式

```
<HEAD> <ID> ; <KEY> = <VAL> [ , <KEY> = <VAL> ] <TAIL>
  $    L01     ON                           \r\n

HEAD: '$' (0x24)   固定帧头，用于丢弃串口噪声
TAIL: CRLF         行结束
校验: 异或和，附在末尾 *XX  (可选，v2 加)
```

完整示例：

```
$S01;T=25.3,H=48,SMOKE=0,PIR=1*4F\r\n     传感器上报
$L01;ON\r\n                               灯开
$C01;POS=50\r\n                           窗帘到 50%
$L01;ST=1,SRC=KEY\r\n                     状态回报（来源：按键）
$SYS;PING\r\n  /  $SYS;PONG\r\n            心跳
$L01;ERR=E02\r\n                          错误
```

### 6.2 错误码

| 码 | 含义 |
|---|---|
| E01 | 帧头错误 |
| E02 | 未知指令 |
| E03 | 参数越界 |
| E04 | 设备忙（电机运行中拒绝新指令） |
| E05 | 校验失败 |

### 6.3 设备 ID

`L` 灯 / `C` 窗帘 / `F` 风扇 / `S` 传感器组 / `P` 面板 / `SYS` 系统

### 6.4 解析状态机（对照用）

```c
/* 建议用状态机而非 sscanf，因为你只有 256B RAM，sscanf 太重 */
typedef enum { S_IDLE, S_HEAD, S_BODY, S_DONE } parse_state_t;
/* 逐字符喂入，遇 '$' 复位，遇 '\r' 置完成 */
```

## 7. 内存预算（256B 怎么花）

这一节是 51 项目独有的功课。**开工前先把账算清楚**，比事后查"为什么跑飞了"省一百倍时间。

| 用途 | 大小 | 说明 |
|---|---|---|
| 串口环形缓冲 | 32B | 存原始字节 |
| 行缓冲 | 40B | 一行最长 40 字符 |
| LCD 显示缓冲 | 34B | 两行 ×16 字符 + 结束符（也可不缓存直接写） |
| 设备状态 `app_state_t` | 8B | 见下 |
| 传感器值 `env_t` | 6B | 温度(2) 湿度(1) 烟雾(1) 人体(1) 时间戳(1) |
| 调度器任务表 | 7×5=35B | 7 个任务 |
| 栈与临时变量 | ~60B | 保守预留 |
| **合计** | **≈ 215B** | 余量 41B |

```c
/* 尽量用位域和最小类型 */
typedef struct {
    uint8  led_mask;      /* 8 路灯 */
    uint8  relay_on : 1;
    uint8  curtain_pos : 7;   /* 0-100 */
    uint8  alarm : 1;
    uint8  cloud_ok : 1;
} app_state_t;   /* 只占 4 字节 */
```

**铁律**：任何新增全局变量，先回这张表加一行。表满了就说明该砍功能了，不是该换芯片了。

原设计稿的验收清单全是正向用例，这里补齐反向用例 —— **故障路径才是区分"能演示"和"能用"的地方**。

## 11. 参考代码对照点

> 只给关键片段，用来**对照你自己的实现**，不是让你抄。

### 11.1 软件 I2C 的位操作骨架

```c
/* 开漏模拟的关键：写 1 之前先写 1 释放总线，再读回确认 */
static void SDA_Out(uint8 v) { SDA = v; }
static uint8 SDA_In(void)    { SDA = 1; return SDA; }  /* 释放后读 */

static void I2C_Start(void) {
    SDA_Out(1); SCL = 1; Delay_us(2);
    SDA_Out(0); Delay_us(2);   /* SCL 高时 SDA 下降 = START */
    SCL = 0;
}
/* 应答检测：发完 8 位后释放 SDA，读第 9 个时钟的电平，0=ACK */
```

### 11.3 DS18B20 时序关键点

```
复位: 拉低 >480µs → 释放 → 等 15-60µs → 读存在脉冲（0=在位）
写1:  拉低 1-15µs → 释放，总时隙 >60µs
写0:  拉低 60-120µs → 释放
读:   拉低 >1µs → 释放 → 15µs 内采样

⚠️ 整个读时隙必须 EA=0 关中断，否则定时器中断插进来就错位
⚠️ 转换命令发出后要等 750ms（12位精度），期间不能干等
```

### 11.4 非阻塞蜂鸣器

```c
/* ❌ 阻塞 */
void Buzzer_Beep(uint16 ms) { Buzzer = 1; Delay_ms(ms); Buzzer = 0; }

/* ✅ 非阻塞：只设截止时刻，由 1ms tick 关掉 */
static uint16 beep_until;
void Buzzer_Beep(uint16 ms) { beep_until = now_ms + ms; Buzzer = 1; }
void Buzzer_Tick(void) { if (beep_until && now_ms >= beep_until) { Buzzer = 0; beep_until = 0; } }
```

## 12. 学习里程碑（每阶段要能讲清的原理）

| 阶段 | 必须能讲清 |

## 13. 风险与对策

| 风险 | 概率 | 对策 |
|---|---|---|
| LCD 点不亮 | 高 | 先查 P0 上拉排阻，再查 PCF8574 地址（0x27 或 0x3F），最后查初始化延时 |
| DS18B20 一直读 -127 | 高 | 90% 是时序问题：关中断、4.7k 上拉、线太长 |
| 电机一转就复位 | 中 | 电机独立供电、共地单点、ULN2003 与 51 之间加 100µF |
| 串口收到乱码 | 中 | 晶振必须 11.0592MHz（不是 12MHz），波特率才算得准 |
| 备考中断导致遗忘 | **高** | 每次开工先看 `docs/01-开发日志.md` 最后一条；每个文件顶部写"引脚+时序+坑" |

# 00 · 计划与验收

## 定位

**这是一个学习项目。** 完成标准不是"能用"，而是"每个模块我都能从零手写出来并讲清原理"。

因此允许：代码丑、走线乱、功能重复、不节能、不实用。
不允许：抄代码不改、模块跑通却讲不出时序、`Delay` 满天飞。

## 阶段一：LED + 按键 + LCD

**目标**：按键控制 8 路 LED，LCD1602 显示当前状态。

| 模块 | 文件 | 验收 |
|---|---|---|
| 延时 | `bsp/delay.c` | `Delay_us(100)` 示波器上确实是 100µs ±5% |
| 软件 I2C | `bsp/i2c_soft.c` | 能读 PCF8574 的应答；时序与 MPU6050 复用同一份代码 |
| LCD1602 | `driver/lcd1602.c` | 显示两行中文/英文混合不乱码，刷新无闪烁 |
| 按键 | `driver/key.c` | 消抖 20ms，连按 20 次误触发 0 次 |
| LED | `driver/led.c` | 8 路独立控制，与 LCD 无冲突 |

**关键差异**：LCD 用 I2C 版，不占用 P2.5/P2.6/P2.7，避免与 LED 打架。

## 阶段二：传感器与告警

| 模块 | 验收 |
|---|---|
| DS18B20 | 读数与室温计误差 < 0.5℃，连续读 100 次无 -127 错误 |
| MQ-2（DO） | 打火机气体靠近 3 秒内触发，移开后 10 秒恢复 |
| HC-SR501 | 人走过 2 米内触发，延迟旋钮调到最短 |
| 蜂鸣器 | 与 LCD 同时工作不卡顿（说明没阻塞） |

## 阶段三：执行机构

| 模块 | 验收 |
|---|---|
| 28BYJ-48 | 正转 512 步能回到原位（无累积丢步）；换向无抖动 |
| 继电器 | 开合 50 次，51 不复位（说明电机干扰处理到位） |

**这一步的价值**：步进电机代码可以直接搬到项目二的窗帘节点，四相八拍表完全一样。

## 阶段四：联网（建议改造）

原设计是 51 拼 AT 指令 + 巴法云。**建议改为**：

```
51 ──UART 行协议──→ ESP32-C3 ──MQTT──→ 巴法云 / 本地 broker
    L01;ON              负责所有网络细节
```

理由：51 的 256B RAM 拼 AT 指令字符串极易溢出；且行协议这套代码在项目二里能直接复用。

验收：
- [ ] 串口助手能看到 51 正确发出的 `S01;T=25.3`
- [ ] 手机通过云平台下发 `ON`，51 收到并点亮 LED
- [ ] 拔掉网线，51 的本地按键仍可用（说明本地逻辑没被网络绑架）

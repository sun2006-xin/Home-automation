# 51-SmartHome — 51 单片机智慧家居（练手项目）

> **这是项目一：把 51 学透。**
> 一块板子、一堆外设、全部有线连接、单机闭环。**不追求分布式，不追求实用**，目标是让 GPIO / UART / 单总线 / ADC / 电机 / 状态机全部过一遍手。

设计稿在 `E:\项目规划\51智慧家居.docx`（四阶段、含完整驱动代码）。本目录是它的落地实现。

---

## 与其他项目的关系

| | 项目一（本目录） | 项目二 [SmartHome](../SmartHome/README.md) |
|---|---|---|
| 目的 | **学习**：把 51 和外设打熟 | **产品**：真正能装进房子的分布式系统 |
| 硬件 | 普中A2 一块板 | 每电器一个 ESP32-C3 + 本地中枢 |
| 拓扑 | 有线、星型、单机 | MQTT 总线、分布式、可异地 |
| 完成标准 | 四阶段各自能演示 | 多节点在线、断网可用、异地可控 |
| 时间 | 碎片时间，书桌上就能干 | 需网购元件 + 整块时间 |

**共用知识**：步进电机四相八拍、LCD 显示、DS18B20 时序、UART 收发 —— 这些在本项目练熟，项目二直接搬过去。
**不共用代码仓库**：两个项目独立推进，任一方停摆不影响另一方。

## 四阶段

| 阶段 | 内容 | 核心技能 | 状态 |
|---|---|---|---|
| 一 | LED + 按键 + LCD1602 + 蓝牙 | GPIO、UART、中断 | ⬜ |
| 二 | DS18B20 + MQ-2 + HC-SR501 + 蜂鸣器 | 单总线、比较器、传感器融合 | ⬜ |
| 三 | 28BYJ-48 步进 + ULN2003 + 继电器 | 电机驱动、PWM、时序 | ⬜ |
| 四 | ESP8266 + 巴法云 + 天猫精灵 | AT 指令、MQTT 概念、云平台 | ⬜ |

> 阶段四建议调整：**ESP 侧改用 C3 跑 MQTT 固件，51 只发行协议**。原因见下方修正第 1 条。

## 必须知道的 4 条修正（照原文档直做会翻车）

原设计稿在资源规划上有硬伤，落地前先改：

| # | 问题 | 修正 |
|---|---|---|
| 1 | **串口独占**：HC-05（阶段一）和 ESP8266（阶段四）都接 P3.0/P3.1，而 89C52 只有 1 个 UART | 二选一。建议阶段四把 ESP 换 C3，51 只发 `L01;ON` 行协议，AT 指令不再由 51 拼 |
| 2 | **引脚冲突**：LED1–8 占 P2.0–P2.7，LCD1602 的 RS/RW/E 又是 P2.6/P2.5/P2.7 | LCD 改用 **I2C 版（PCF8574）**，只需 2 个 IO，一次性释放 3 个引脚 |
| 3 | **按键撞串口**：K1–K4 = P3.0–P3.3，串口也在这 | 只用 **K3/K4（P3.2/P3.3）** |
| 4 | **P3.5/P3.7 三方复用**：DS1302 / DS18B20 / XPT2046 | 去掉 DS1302（时间由 ESP 经 NTP 给）；MQ-2 改用模块的 **DO 数字输出**，不走 XPT2046 的 ADC |

完整的 8 条审查见 [../SmartHome/docs/03-原方案技术审查.md](../SmartHome/docs/03-原方案技术审查.md)。

## 编码约定

- 主循环**禁止** `Delay_ms(>10)`，一律定时器计数做非阻塞
- 驱动层不写业务判断（`if (temp > 30)` 属于 app 层）
- 每个驱动文件顶部写清：引脚、时序要求、已知坑
- 全局变量一律 `static`，跨文件 `extern`

# 05 · 术语表

> 只收录本项目真正会用到的概念。每个词给一句人话解释 + 一句在本项目里的落地方式。

## 通信基础

| 术语 | 人话解释 | 本项目里是什么 |
|---|---|---|
| **MQTT** | 一种轻量的"发消息"协议，设备只连一个中心，不互相对连 | 全项目唯一的对外通信协议 |
| **broker** | 消息中转站。像微信群：你发到群名上，订阅的人都能收到；它只看"发到哪个群"，不看内容 | 家里一台常开设备（路由器/旧手机/树莓派）跑 Mosquitto |
| **client** | 连到 broker 的任何一方 | 每个 C3 节点、51 面板、手机、上位机都是 client |
| **topic（主题）** | 消息的"群名"，用斜杠分层 | `sh/h01/L01/cmd` |
| **publish（发布）** | 往某个主题发一条消息 | 节点上报状态、手机下发指令 |
| **subscribe（订阅）** | 告诉 broker "这个主题有消息请通知我"，支持通配符 `+`（单层）和 `#`（多层） | 51 面板订阅 `sh/h01/+/state` 拿到全屋状态 |
| **QoS** | 消息送达保证等级：0 最多一次 / 1 至少一次 / 2 恰好一次 | 控制指令用 1，状态用 1，心跳用 0 |
| **retain（保留）** | broker 记住某个主题的最后一条消息，新订阅者一连上就立刻收到 | 所有 `state` 主题都开，手机打开 App 立刻看到当前状态 |
| **LWT（遗嘱消息）** | 设备连上时先跟 broker 约定："我要是掉线了，你就替我发这条" | 掉线自动发 `sh/h01/L01/online = 0`，面板立刻知道谁不在 |
| **keepalive（心跳）** | 客户端每隔一段时间说一句"我还在"，超时 broker 就判定掉线 | 30 秒一次，3 次无响应转 RETRY |
| **bridge（桥接）** | 让两台 broker 自动同步消息，对外像一个网络 | 家里 broker ←1 条连接→ 云 broker，节点对云完全无感 |

## 网络

| 术语 | 人话解释 | 本项目里是什么 |
|---|---|---|
| **STA 模式** | 设备像手机一样去连别人的 WiFi | 节点正常工作时 |
| **AP 模式** | 设备自己当热点，别人来连它 | 装现场、无路由器时调试用 |
| **BLE** | 低功耗蓝牙。不需要路由器，手机直接连设备 | 手机近场直控节点，最兜底的一层 |
| **内网穿透** | 把家里的服务"开一扇窗"到公网，让外面能访问 | M4 异地控制，frp / Cloudflare Tunnel / Tailscale |
| **局域网 / LAN** | 同一个路由器下的设备互相能看见 | 家 broker 所在的网络 |

## 硬件与固件

| 术语 | 人话解释 | 本项目里是什么 |
|---|---|---|
| **C3 / ESP32-C3** | 一颗自带 WiFi + BLE 的国产芯片，约 12 元 | 每个电器的"网卡 + 边缘大脑" |
| **GPIO** | 芯片上能读能写的引脚 | 控制继电器、读传感器 |
| **UART** | 串口，两根线（TX/RX）收发 | 51 与 C3 之间唯一的通信方式 |
| **I2C** | 两根线（SCL/SDA）挂多个设备的总线 | 软件模拟，驱动 I2C LCD1602、MPU6050 |
| **OTA** | 隔空升级固件，不用插 USB | 节点装进墙盒后唯一的升级途径 |
| **NVS** | 芯片里掉电不丢的小存储区 | 存 WiFi 账号、device_id |
| **看门狗** | 程序卡死时自动重启的保护 | 防止节点假死在线 |

## 本项目自定义

| 术语 | 含义 |
|---|---|
| **节点（node）** | 一个电器 + 一块 C3，是本项目的最小单元 |
| **link 层** | C3 固件里决定"怎么控制电器"的一层：`link_gpio` 直接驱动 / `link_serial` 与 51 对话 |
| **行协议** | 51 与 C3 之间的 ASCII 文本协议，如 `L01;ON\r\n`，51 只认这个 |
| **device_id** | 节点身份，如 `L01`。同一份固件烧 N 份，只改这个 |
| **home_id** | 部署地点标识，如 `h01`（家）、`h02`（老家） |
| **规则中枢** | 51 的角色：订阅全部状态、跑联动规则、下发指令，但**不转发数据** |
| **流量中枢** | 51 **不是**这个角色：不做 broker、不做网关、不搬运行李 |

## 五、维护约定

1. **新增文档必须在本表登记**，否则视为不存在，将来自己都找不到
2. **被取代的文档移入 `_archive/`**，不删除 —— 保留推导过程比保留结论更有价值
3. **开发日志不改历史**，只往后追加
4. 文档超过 300 行就该拆分；少于 50 行就该考虑合并

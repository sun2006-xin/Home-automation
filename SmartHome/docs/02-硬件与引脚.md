# 02 · 硬件与引脚

> ⚠️ 本文档的引脚分配**必须与实物原理图核对后再落地**。
> 普中A2 开发板资源存在多处板载复用，原方案文档未完全规避（见第 3 节）。

## 1. 主控与板卡

| 项 | 型号 | 说明 |
|---|---|---|
| 开发板 | 普中A2 | 板载 STC89C52RC |
| 主控 | STC89C52RC | 8051 内核，8KB Flash / 512B RAM（其中 256B 内部 RAM），11.0592MHz 晶振 |
| 编程 | STC-ISP（串口下载） | 注意：下载与运行共用 P3.0/P3.1 |

## 2. 引脚分配表（v1 定稿）

### 2.1 已占用（板载固定）

| 功能 | 引脚 | 备注 |
|---|---|---|
| LCD1602 数据 D0–D7 | P0.0–P0.7 | P0 必须外接 10k 上拉排阻 |
| LCD1602 RS / RW / E | P2.6 / P2.5 / P2.7 | **与 LED5–LED7 冲突，见 3.1** |
| LED1–LED8 | P2.0–P2.7 | 共阳极，低电平点亮 |
| 独立按键 K1–K4 | P3.0–P3.3 | **K1/K2 与串口冲突，见 3.2** |
| 串口 RXD / TXD | P3.0 / P3.1 | 唯一 UART，**不可分割** |

### 2.2 外部模块分配（建议方案）

| 模块 | 接口 | 建议引脚 | 说明 |
|---|---|---|---|
| ESP 无线节点 | UART | P3.0 / P3.1 | 唯一串口，全项目独占 |
| DS18B20 温度 | 单总线 | P3.7 | 需 4.7k 上拉；**与 XPT2046 冲突** |
| MQ-2 烟雾 | 数字量 DO | P1.7 | **不用 ADC**，用模块自带比较器输出，见 3.4 |
| HC-SR501 人体 | 数字量 | P3.4 | 高电平有效，可延长线引出 |
| 蜂鸣器 | GPIO | P2.3 或板载 | 若板载则复用 |
| 28BYJ-48 步进 | 4 线 ULN2003 | P1.0–P1.3 | 顺序 IN1–IN4 |
| 继电器（风扇） | GPIO | P1.4 | 注意高/低电平触发，模块通常低触发 |
| 备用 | — | P1.5 / P1.6 | 留给后续节点扩展 |

### 2.3 若改用 I2C LCD1602（强烈建议）

用 **PCF8574 + 软件 I2C** 驱动 LCD1602，可一次性释放 P2.5 / P2.6 / P2.7 三个引脚：

| 信号 | 引脚 | 说明 |
|---|---|---|
| SCL | P1.5 | 软件模拟，10k 上拉 |
| SDA | P1.6 | 软件模拟，10k 上拉 |

**收益：** 释放 3 个 IO、消除 3.1 冲突、且与你正在学的"软件 I2C 写 MPU6050"完全同源 —— 这套软件 I2C 代码可以直接复用，只换从机地址。

## 3. 引脚冲突审查（重要）

### 3.1 LCD1602 控制线 vs LED5–LED7

原方案同时使用了 `LED1–LED8 = P2.0–P2.7` 和 `LCD1602 RS/RW/E = P2.6/P2.5/P2.7` —— 同一组引脚。

**影响：** LCD 刷新时 LED5–LED7 会随 E 信号闪烁；反之操作 LED 会打乱 LCD 时序。

**方案：**
- 甲（推荐）：改用 **I2C LCD1602**（PCF8574），彻底释放 P2 口。
- 乙：只用 LED1–LED4（P2.0–P2.3）做状态指示，LED5–LED7 让给 LCD。

### 3.2 独立按键 K1/K2 vs 串口 P3.0/P3.1

原方案写 `K1–K4 = P3.0–P3.3`，同时串口也占 P3.0/P3.1。**接上 ESP 后，按 K1/K2 会向串口注入电平变化，扰乱通信；串口数据也会误触发按键。**

**方案：**
- 只使用 **K3 / K4（P3.2 / P3.3）** 作为本地按键。
- 若需要更多按键：用 P1 剩余引脚 + 外部按键，或改用 ADC 按键（电阻分压）—— 但 51 无 ADC，需外挂。

### 3.3 P3.5 / P3.7 三方复用（原文档已警告）

`P3.5` 同时是 DS1302 的 CE、`P3.7` 同时是 DS1302 的 I/O、DS18B20 数据线、XPT2046 的 SPI 线。

**影响：** 任何一个器件拉低总线，其他器件读数异常。原文档提了但没给方案。

**方案：** 本项目**不使用 DS1302**（时间由 ESP 从 NTP 取，通过行协议下发，更准且省引脚）。若必须保留 RTC，则只在需要读时间时短暂使能 DS1302 的 CE，其余时间置高。

### 3.4 MQ-2 走 XPT2046 ADC 的问题

原方案用 XPT2046 读 MQ-2 模拟量。问题：

1. XPT2046 是**触摸屏专用**芯片，与板载触摸屏共用 SPI 线，会互相打断。
2. MQ-2 需要预热 20 分钟以上，模拟输出漂移大，阈值标定困难。
3. 51 无硬件 ADC，这套链路调试成本高于收益。

**方案：** 直接用 MQ-2 模块的 **DO（数字量）输出**脚 —— 模块自带 LM393 比较器，电位器可调阈值，接一个普通 IO 即可。需要"数值趋势"时再考虑 ADC。

### 3.5 串口独占（全项目最硬的约束）

STC89C52RC 只有 **1 个 UART**。原方案中：

- 阶段一：HC-05 接 P3.0/P3.1
- 阶段四：ESP8266 接 P3.0/P3.1

**两者不能同时存在。** 详见 docs/03 第 1 条。

## 4. 电平与供电

| 风险点 | 说明 | 对策 |
|---|---|---|
| ESP-01S 供电 | 峰值电流可达 300mA，51 板 3.3V 输出常不足 | 独立 3.3V LDO 或 AMS1117 模块，加 100µF 电容 |
| 5V → 3.3V 电平 | ESP 的 RXD 不耐 5V，51 的 TXD 是 5V | 电阻分压（1k + 2k）或电平转换模块 |
| ESP 的 TX → 51 的 RX | 3.3V 高电平，51 判为高（>2.0V） | 通常可直连 |
| 步进电机干扰 | 电机启动瞬间拉低电源，导致 51 复位 | 电机电源独立，共地单点连接 |
| 继电器反向电动势 | 线圈断电产生尖峰 | 模块自带续流二极管；否则外并 1N4148 |

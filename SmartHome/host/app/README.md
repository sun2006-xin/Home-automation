# host/app — 上位机（M6 开始）

两条可选路线，先做前面那个：

| 路线 | 技术 | 优势 | 劣势 |
|---|---|---|---|
| A | PyQt5 + paho-mqtt | 复用正在学的 PyQt5；可做专业界面 | 要自己写界面 |
| B | Home Assistant / MQTT 面板 | 开箱即用，图表齐全，手机友好 | 学 YAML 配置，自定义受限 |

建议：**先用 B 快速拿到可用界面（半天），再用 A 做定制版**。B 能让你立刻看到"分布式节点同时在线"的效果，A 用来练 PyQt5。

## 界面最小功能集

- [ ] 设备列表（在线 / 离线 / 最后心跳时间）
- [ ] 每个设备的开关与状态
- [ ] 传感器实时曲线（温度、烟雾、人体）
- [ ] 报警记录（时间 + 类型 + 确认）
- [ ] 场景开关（回家 / 离家 / 睡眠）

## 通信

只用 MQTT，不直连串口。这样上位机可以跑在任意一台机器上（包括云服务器），与节点物理位置解耦 —— 这也是"异地可用"的最后一块拼图。

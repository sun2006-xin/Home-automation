# hardware/pinmap.md — 12V 全模拟方案

> **定位**：不接 220V。全部 12V 直流，用于验证架构、协议、状态同步与故障逻辑。
> **接线逻辑与真实强电完全一致**（并联旁路 + 电流检测），只是电压安全。
> 保真度边界见 `docs/11-产品与功能设计.md` 第 9.2 节 —— 能证明架构，不能证明安规。

---

## 1. 单路回路骨架

```
日常：按钮(接 MCU 输入) ─信号→ MCU ─驱动→ 继电器 ─→ 负载
供电：12V ─ 保险 ─→ 三档选择器 ─┬─ ① 自动   → 继电器
                                ├─ ② 强制开 → 负载（直通）
                                └─ ③ 强制关 → 断路
回读：三档选择器 ─档位信号→ MCU（2 个 GPIO 或 1 个 ADC）
检测：负载侧 ─→ 光耦 ─→ MCU（判断灯到底亮没亮）
```

**五个要点：**

1. **日常按钮不直接通断负载**，只给 MCU 位置信号。
   > 并联（开关 ‖ 继电器）看起来更可靠，但它是"或"逻辑 ——
   > 物理开关闭合时，继电器断开也没用，**手机永远关不掉手动开的灯**。
2. **三档选择器管"模式"，不管日常**：自动 / 强开 / 强关，覆盖"MCU 死机"和"检修断电"两种场景。
3. **档位要回读给 MCU**，否则界面会一直显示"可控"，用户点了没反应。
4. **电流检测管"事实"**：开关位置是意图，光耦检测出的电流才是真相（防触点粘连、灯泡坏）。
5. **保险在前**：任何一路短路，先断保险，不烧电源。

## 4. 供电与保护细则

| 项 | 要求 |
|---|---|
| 主电源容量 | 12V / **3A 以上**（步进 + 多路继电器同时动作会叠加大电流） |
| 步进供电 | 单独一路或就地并 **1000µF** 电解电容，吸收启动冲击 |
| 共地 | 所有模块 GND 汇到**一个点**，避免地环路导致 MCU 复位 |
| 继电器续流 | 模块通常自带；裸继电器必须外并 1N4148 |
| 每路保险 | 自恢复保险丝 500mA，串在负载前 |
| C3 供电 | 12V → LM2596 → 5V → C3 的 5V 脚（**不要**直接 12V 进 C3） |
| 走线 | 12V 主干与信号线分开走，不要长距离平行贴太近 |

## 5. 三个最容易踩的坑

| # | 坑 | 现象 | 解法 |
|---|---|---|---|
| 1 | **继电器 3.3V 推不动** | 轻微咔哒但不吸合，或完全不动作 | 买明确标 3.3V 兼容的模块；或继电器供 5V，用三极管/MOS 驱动 IN |
| 2 | **步进一动就复位** | 电机启动瞬间 MCU 重启 | 电机独立供电 + 1000µF + 共地单点。12V 一样会复现，别以为低压就没事 |
| 3 | **光耦接反或漏接地** | 检测脚恒高或恒低 | 输入端串 1k 限流、输出端 10k 下拉；先用万用表量电压再上电 |

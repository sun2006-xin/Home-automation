# 嵌入式项目仓库

一个项目：**分布式智慧家居系统** —— 一个电器一个节点，判断归节点，断网也能用。

> 📍 直接看 **[SmartHome/PROJECT.md](./SmartHome/PROJECT.md)** —— 一页看懂：有哪些东西、各有什么功能、怎么连起来。

## 技术栈

| 层 | 选型 |
|---|---|
| 节点 | ESP32-C3 SuperMini（WiFi + BLE） |
| 通信 | MQTT（本地 broker + 云端通道） |
| 中枢 | 旧手机 / 树莓派 / 路由器跑 Mosquitto |
| 界面 | 手机 PWA + Web 仪表盘 + 壁挂终端 |
| 硬件 | 12V 全直流模拟，不接 220V |

## 项目性质

本项目是**最大程度模拟**，目的是快速验证架构与想法，不是可上市的产品。

- 全部 12V 直流，**不接 220V**
- 产品化（安规、EMC、可靠性、3C 认证、量产）是商家的事
- **能证明**：拓扑逻辑、通信协议、状态同步、场景编排、故障模式
- **不能证明**：电气安全、负载特性、发热与线径、EMC、安规认证

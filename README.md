# 嵌入式项目仓库

两个独立的嵌入式项目，各自单文件夹开发，互不依赖。

| 项目 | 定位 | 硬件 | 说明 |
|---|---|---|---|
| **[51-SmartHome](./51-SmartHome/)** | **学习项目**：把 51 与外设打熟 | 普中A2（STC89C52RC）单板，有线 | 四阶段迭代，不追求实用 |
| **[SmartHome](./SmartHome/)** | **产品项目**：分布式智慧家居 | 每电器一块 ESP32-C3 + 本地中枢 | 12V 全模拟，分八期建设 |

> 想快速了解分布式那个项目，直接看 **[SmartHome/PROJECT.md](./SmartHome/PROJECT.md)** —— 一页看懂。

## 两个项目的关系

- **共用知识**：步进电机时序、LCD 显示、传感器驱动、行协议
- **不共用代码**：仓库隔离，任一方停摆不影响另一方
- **51 面板**：作为 SmartHome 的"物理按键条"使用，不承担网络与决策

## 项目性质声明

本项目是**最大程度模拟**，目的是快速验证架构与想法，不是可上市的产品。

- 全部 12V 直流，**不接 220V**
- 产品化（安规、EMC、可靠性、3C 认证、量产）是商家的事
- **能证明**：拓扑逻辑、通信协议、状态同步、场景编排、故障模式
- **不能证明**：电气安全、负载特性、发热与线径、EMC、安规认证
